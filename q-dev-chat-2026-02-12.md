# 📊 **TestLink + MCP API - Asistente Inteligente de Consultas**

## 🎯 **¿Qué es este proyecto?**

Un **asistente conversacional con IA** que permite consultar información de TestLink usando **lenguaje natural**, diseñado especialmente para **ayudar a compañeros nuevos** a encontrar casos de prueba, proyectos y planes sin necesidad de navegar por la interfaz tradicional.

---

## 🧠 **Arquitectura: RAG + Agente IA**

### **Componentes principales:**

1. **TestLink** (Puerto 8080)
   - Sistema de gestión de pruebas con PostgreSQL
   - Base de datos persistente con casos, planes y resultados

2. **MCP API** (Puerto 8012)
   - API FastAPI con integración a **Google Gemini 2.5 Flash**
   - Arquitectura **RAG (Retrieval-Augmented Generation)**
   - **Agente con 10 herramientas especializadas**

3. **Orquestación Docker**
   - Makefile para gestión simplificada (`make up`, `make down`)
   - Red compartida entre servicios
   - Configuración automática con `setup-testlink.sh`

---

## 🔍 **Enfoque: Consultas Básicas y Avanzadas**

### **¿Por qué solo consultas?**

✅ **Prioridad 1:** Ayudar a nuevos miembros del equipo a:
- Listar proyectos disponibles
- Buscar casos de prueba por palabras clave
- Ver detalles de suites y planes
- Consultar resultados de ejecuciones

❌ **Creación de casos:** Funcionalidad disponible pero **no es el foco principal**
- Es más sencillo crear casos directamente en TestLink
- El valor real está en **encontrar información existente rápidamente**

---

## 🛠️ **Herramientas de Consulta Disponibles**

### **Consultas Básicas:**
1. `list_projects` - Listar todos los proyectos
2. `list_test_suites` - Ver suites de un proyecto
3. `list_test_plans` - Listar planes de prueba
4. `list_builds` - Ver builds de un plan

### **Consultas Avanzadas:**
5. `search_tests` - **Búsqueda global por palabras clave**
   - Busca en nombres, resúmenes y pasos
   - Puede filtrar por proyecto específico
   
6. `list_test_cases_in_suite` - **Ver todos los casos de una suite**
   - Incluye autor, resumen y ID externo
   - Formato tabular para fácil lectura

7. `get_test_case_details` - **Detalles completos de un caso**
   - Precondiciones, pasos, resultados esperados
   - Historial de creación y autor

8. `read_test_execution` - **Resultados de ejecución**
   - Estado (pass/fail/blocked)
   - Notas y fecha de ejecución

9. `list_requirements` - Requisitos del proyecto

10. `read_test_case` - Datos raw de un caso específico
